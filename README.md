# evripidis-updates

Δίαυλος ενημερώσεων για μια εσωτερική εφαρμογή καταχωρήσεων.

Ό,τι υπάρχει εδώ είναι **κρυπτογραφημένο** (Fernet / AES-128 με έλεγχο γνησιότητας)
και χωρίς το κλειδί δεν σημαίνει τίποτα. Το repo είναι δημόσιο επειδή χρειάζεται
απλώς να είναι **αναγνώσιμο χωρίς λογαριασμό** — όχι επειδή το περιεχόμενο είναι
δημόσιο.

| Αρχείο | Τι είναι |
|---|---|
| `latest.json` | ο δείκτης: ποια είναι η τρέχουσα έκδοση και πού κάθεται |
| `update_<έκδοση>.enc` | το πακέτο της έκδοσης, κρυπτογραφημένο |

Ο δείκτης ανεβαίνει **τελευταίος**, αφού επαληθευτεί ότι το πακέτο κατεβαίνει.
Διαφορετικά θα έδειχνε σε 404 και κάθε εγκατάσταση θα προσπαθούσε ξανά και ξανά.

Το κλειδί **δεν ανεβαίνει ποτέ εδώ** — ζει μόνο μέσα στις εγκαταστάσεις.
